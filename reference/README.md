# Reference cards

One HTML card per study element. The card is the compressed form of the lesson. It is
designed for quick review and print.

## When to create a card

Create the card after the explain-back. The learner writes the definition. The card is
evidence of understanding, not a substitute for it.

## File name

`{ID}-{slug}.html`.

## Required parts

1. Definition.
2. Formula.
3. Failure mode.
4. One worked micro-example.
5. The source section.

## Global references

These are not element cards. They are the map, the math plan, the status board, and the
glossary.

| File | Content |
| --- | --- |
| `curriculum.html` | The core path and the rules. |
| `math-map.html` | The Strang sections and the assigned problems. |
| `progress.html` | The status tables and the retrieval queue. |
| `glossary.html` | The canonical glossary. Edit the HTML directly. |

## Rules

- Link `../assets/lesson.css`.
- One card per element.
- Use the glossary terms.
- Revise the card when understanding deepens.
