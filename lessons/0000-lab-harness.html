Training error is not a test

You can fit a line through two points exactly. The training error is zero. That number does not tell you whether the line will work on a new point.

One example

Fit a line through (0,1) and (1,3). The line passes through both points. The training MSE is 0.

Fit a line through (0,5) and (1,−2). The line passes through both points. The training MSE is 0 again.

The result is the same for any pair of points. The fit uses the points that score it. The number is fixed by the setup, not by the data.

The mechanism

The model f̂ comes from the training set. The test set supplies new (x₀, y₀) pairs. The test error measures f̂ on data it did not see.

The rule

Fit on train. Measure on validation. Touch the test set once, for the final number.

Retrieval

Why is the training MSE zero for a 2-point line, and why is that not evidence of a good model?

Show answer

The line has two parameters and two points. It can pass through both points. The score uses the same points that set the parameters, so the score is fixed at zero. It says nothing about a new point.
