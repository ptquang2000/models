# Lessons

One HTML lesson per study element. The lesson teaches one idea. It is not the model code.
The learner writes the code.

## When to create a lesson

Create the lesson when the element starts. Do not create lessons ahead of the path. The
study element is the contract. The lesson is the teaching.

## File name

`{ID}-{slug}.html`, where `{ID}` is the build ID. Example:
`0001-linear-regression-closed-form.html`.

## Required parts

1. One idea.
2. One numeric example.
3. One source section.
4. One retrieval question.
5. One follow-up prompt.
6. A link to the study element.
7. A link to the reference card, when it exists.
8. A link to `../assets/lesson.css`.

## Rules

- Link the shared stylesheet. Do not inline a second style system.
- Keep the lesson short. Working memory is small.
- Cite the source for every claim.
- Do not paste a reference implementation.
- Do not put the answer to the assigned problem in the lesson.
- Use the glossary terms.
- Each quiz answer has the same number of words. Vary the correct position.
